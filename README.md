# 🏆 Auction House

A modern and interactive online auction platform where users can explore items, view descriptions, and discover products available for auction. The project features a premium interface with elegant styling and organized product categories.

## 🌐 Live Demo

**[View Auction House](https://vanshika2723.github.io/Auction-House/)**

## 📂 GitHub Repository

**[View Source Code](https://github.com/vanshika2723/Auction-House.git)**

## ✨ Features

- 🎨 Modern and attractive user interface
- 🛍️ Item listing and product descriptions
- 🗂️ Multiple product categories
- 💰 Starting prices displayed in Indian Rupees (₹)
- 🖼️ Organized product presentation
- 💾 LocalStorage support for browser-based data persistence
- 📱 Responsive layout for different screen sizes
- ⚡ Interactive functionality using JavaScript

## 🗂️ Available Categories

- Art & Paintings
- Antiques & Collectibles
- Jewelry & Watches
- Luxury & Automobiles

## 📝 Item Listing Details

Users can provide the following information when listing an item:

- Item Title
- Category
- Description
- Starting Price (₹)

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, layout, and responsive design
- **JavaScript** — Interactive functionality and browser storage
- **LocalStorage** — Saving supported data in the browser

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/vanshika2723/Auction-House.git
   ```

2. Open the project folder:

   ```bash
   cd Auction-House
   ```

3. Open `index.html` in your browser.

## 💡 Project Purpose

Auction House was developed as a web development project to practice frontend development, interactive forms, product categorization, responsive design, and browser-based data storage.
